# 3 Post via Scheduler

**Pembicara:** Rino Damar Jati  
**Topik:** Posting Threads via scheduler (Repli)

## Poin Penting

- Rino menggunakan **Repli** sebagai content scheduler (alternatif: Buffer).
- Keunggulan Repli: UI lebih enak, bisa split view dengan Threads untuk copy-paste cepat.
- **Workflow:**
  1. Copy konten dari AI (format box).
  2. Buka Repli, klik tambah.
  3. Paste konten, atur jadwal (bisa langsung atau dijadwalkan).
  4. Simpan, otomatis terposting.
- Tips: Gunakan split view Chrome (klik kanan → Add tab to new split view) untuk mempercepat copy-paste.
- Waktu yang dibutuhkan: 1-2 menit per posting.

## Takeaways

- Scheduler menghemat waktu dan memungkinkan konsistensi posting.
- Pilih tools dengan UI yang nyaman (Rino rekomendasi Repli).
- Split view mempercepat workflow copy-paste.

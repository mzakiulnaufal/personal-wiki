# Claude Code Course — Overview

A 10-section masterclass (AI Automation by Jack) teaching agentic software building with **Claude Code**. The core promise: *"if you can imagine it, you can build it."* Goes from zero to deployed websites/apps and a monetized AI business using the same tools and systems Jack uses daily.

## The Agentic Engineering Thread

This course is a practical companion to the wiki's [[wiki/Concepts/Agentic Engineering|Agentic Engineering]] hub. Recurring power principles across levels:

- **One task = one window.** Protect the context window against [[wiki/Claude Code Course/Power Features|context rot]].
- **Parallel agents & sub-agents** for speed and diverse perspectives.
- **Skills** encode repeatable process ("skills are the difference between a joe and a pro").
- **Version control via GitHub** as the safety net for everything built.
- **Memory systems** so AI never forgets — see [[wiki/Claude Code Course/Memory System|Memory System]].
- **Business-first, AI-second** — find the constraint before building ([[wiki/Claude Code Course/Monetization|Monetization]]).

## Builders' Philosophy (High Agency)

- Everything that feels fixed (price, timeline, headcount) is *"usually a recommendation in disguise"* — only physics is load-bearing ([[wiki/Claude Code Course/First Principles|First Principles]]).
- Compounding value: *value × eyeballs*. Build attention; money flows downstream ([[wiki/Claude Code Course/Monetization|Monetization]]).
- Never ship without external review — bring fresh models/agents to critique your work (autonomous critic loop, [[wiki/Claude Code Course/Power Features|Power Features]]).
